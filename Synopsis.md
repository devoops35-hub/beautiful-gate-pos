# Beautiful Gate - Stationery & Printing Hub

## Project Overview
This project is a POS (Point of Sale) system for **Beautiful Gate**, a stationery and printing hub. Built with Node.js and React, it allows users to add, remove, and update products in the database. It also allows users to make sales and generate reports in real-time.

The frontend is built with React + Vite and Tailwind CSS, while the backend is built with Node.js + Express. The database uses SQLite.
The features of the POS are:
- Add products
- Remove products
- Update products
- Make sales
- Generate reports
- Authentication

PAGES:
The various pages will be

- Register
- Dashboard
- Inventory
- Sales
- Reports
